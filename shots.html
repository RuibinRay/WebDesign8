Shot sheet

Every image and scroll film the Horæ site needs. The six film stills are made; the rest is not. Each prompt carries the same look bible word for word, and every stage 2 shot takes its watch’s master as a reference image, so the same watch appears in every picture. Stage 3 makes each film’s later stills from its first one, so both ends share one camera; stage 4 turns each pair into a film.

Automatic (Higgsfield CLI)

  1. node higgsfield/generate.mjs prints the plan, the cost of each image and the balance. It spends nothing.
  2. node higgsfield/generate.mjs --go makes stage 1, then stage 2 with the masters as references, then stage 3 (the films’ later stills) and stage 4 (the films), then runs the optimiser. Look at the stage 3 stills beside their first frames before letting stage 4 run: node higgsfield/generate.mjs images --go stops before the films.
  3. Re-roll one: node higgsfield/generate.mjs family --go --force

By hand (Higgsfield app)

  1. Copy a prompt below. Use the model and aspect it shows; for stages 2 and 3 attach the named reference image; for a film, give Kling 4.0 the start and end frames shown.
  2. Save the download as higgsfield/renders/<id>.png (films: <id>.mp4; cutting them into frames needs ffmpeg).
  3. Run npm install once, then node higgsfield/optimize.mjs, and reload.
